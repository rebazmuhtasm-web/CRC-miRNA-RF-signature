# Data availability

Raw sequencing data are not stored in this repository. They are publicly
available through NCBI SRA/GEO under the following accessions:

- PRJNA387172
- GSE125961
- GSE183437
- GSE236991

The preprocessing scripts retrieve or process the corresponding run accessions
and generate the count matrices required by the downstream R workflows.

Before running the analysis, review the user-settings blocks in each script and
replace workstation-specific paths with locations appropriate to the local
environment.
